# Ваш бизнес — демонстрационный сайт

Пример современного сайта для бизнеса в Уральске. Один сайт показывает шесть вариантов: **кофейня, ресторан, салон красоты, барбершоп, стоматология, фитнес-клуб**. Тип бизнеса переключается кнопками внизу экрана без перезагрузки страницы.

Сделан на чистых HTML, CSS и JavaScript: без установки программ, без npm и сборщиков.

## Как открыть

Дважды щёлкните по файлу `index.html` — сайт откроется в браузере. Для фотографий и шрифтов нужен интернет.

## Ссылки для клиентов

К адресу сайта можно добавить `?biz=...`, и сайт сразу откроется с нужным типом бизнеса:

| Бизнес | Что добавить к ссылке |
|---|---|
| Кофейня | `?biz=coffee` |
| Ресторан | `?biz=restaurant` |
| Салон красоты | `?biz=beauty` |
| Барбершоп | `?biz=barber` |
| Стоматология | `?biz=dental` |
| Фитнес-клуб | `?biz=fitness` |

Пример: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/?biz=barber`

## Структура

```
index.html      — разметка страницы
css/style.css   — оформление (цвета категорий в начале файла)
js/script.js    — контент, контакты и логика
README.md       — эта инструкция
.nojekyll       — служебный файл для GitHub Pages
```

## Что и где менять

Всё редактируется в начале файла `js/script.js`:

- **Контакты** — объект `SITE`: телефон, номер WhatsApp, ссылка на Instagram, адрес, ссылка на карту.
- **Ваши контакты разработчика** — `developerWhatsapp` и `developerMessage` (кнопки «Хочу такой сайт» и «Обсудить сайт»).
- **Тексты, услуги, цены, отзывы, FAQ, фото** — объект `BUSINESSES`, отдельный блок для каждого типа бизнеса. Цены указываются числом в тенге, например `price: 4900`. Чтобы добавить «от», укажите `from: true`.
- **Фото** — ID фотографии с Unsplash (часть ссылки после `photo-`) или путь к своему файлу, например `'img/hall.jpg'`.
- **Цвета** — в начале `css/style.css`, строки `body[data-business="..."]`.

Все контакты, адрес, цены и отзывы на сайте — **демонстрационные**. Номер `+7 700 000 00 00` нужно заменить на реальный.
